Psychrometric Load Calculator - iPhone / Chrome App

WHAT THIS PACKAGE IS

This is a mobile-friendly web app package.
It opens in Chrome on a computer.
It can also become an app icon on an iPhone after it is uploaded to any HTTPS web host.

IMPORTANT IPHONE NOTE

An iPhone cannot install a normal app directly from an HTML file sent in iMessage.
For iMessage sharing, upload this folder to a web host, then send the web link.
The same link opens in Chrome and can be added to the iPhone Home Screen.

FILES

- index.html
- OPEN IN CHROME - Mac.command
- manifest.webmanifest
- service-worker.js
- icons/

LOCAL TEST ON THIS MAC

Double-click:
OPEN IN CHROME - Mac.command

Or open Terminal in this folder and run:
python3 -m http.server 4173

Then open this address in Chrome:
http://localhost:4173

SEND BY IMESSAGE

After uploading the folder to a web host, send the web address in iMessage.
The person can open the link in Chrome.

ADD TO IPHONE HOME SCREEN

On iPhone, open the hosted link, use the browser share button, then choose Add to Home Screen.
After the first load, the calculator is cached for offline use.

PRIVATE DATA

The calculator runs in the browser.
It saves the current input values on the device only.
